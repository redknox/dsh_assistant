Status: **Implemented** as the product-version seal for Issue #53. The annotated git tag `v0.3.0` is created only on the exact `main` commit after merge. This file records soak configuration and release-drill evidence. It does not add capability.

```text
v0.2.0 = Governed Self-Extension baseline
v0.3.0 = Product Soak baseline = M1–M5 + Product Readiness
```

Local soak injection (chmod 600; never commit):

```sh

# DSH_ASSISTANT_GOOGLE_CALENDAR_MODE=live
# DSH_ASSISTANT_GOOGLE_CALENDAR_ACCESS_TOKEN=
```

No OAuth refresh subsystem is added for this seal. No public npm publish. No internal vault.
