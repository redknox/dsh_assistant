## Bounded packaged cross-slice soak

Harmless local fixtures only. No live Calendar/Search side effects. Twelve required steps:

1. Bind one Profile and explicit Workspace
2. Two topic Sessions; switch; restart; recover current Session without bleed
3. WUI Profile / Workspace / Session / system state from authoritative DTOs
4. One generated or imported plugin: exact review/approval, separate activation
5. Use, then disable or uninstall; discovery/WUI agree
6. Activate and invoke one harmless DSH-native Skill
7. Update or rollback Skill; exact catalog revision after restart
8. Safe Mode withholds user/generated/third-party plugins and Skills; diagnostics/Recovery remain
9. Recover last valid state
10. Backup/restore; reject one tampered artifact/digest
11. Approval/activation not permanently appended to chat tails
12. Activity/status/doctor: bounded facts; no CoT, secrets, full instructions, or unsafe paths
